# Mobile Games Strategy Research (July 2026)

Multi-agent research program: 7 specialist panels + 4 genre deep-dives, each run as a
separate Opus agent with live 2024–26 web research and evidence tagging
([EB] evidence-backed / [PU] plausible-unverified / [SPEC] speculative), synthesized by
the orchestrating strategist.

## The deliverable

**[`mobile-games-opportunity-framework.md`](mobile-games-opportunity-framework.md)** —
the full opportunity map & decision framework:
terminology map → market landscape → segment-by-segment evaluation → false positives →
monetization & retention architectures → technical scope matrix → Pakistan/regional angle →
8 opportunity territories → weighted decision rubric (with hard gates and kill/scale metrics) →
final synthesis.

## Standing caveat

Many primary analyst pages (Sensor Tower, AppMagic, Naavik, DoF, PocketGamer.biz, GameAnalytics
PDFs) blocked direct fetch during research; figures were recovered via indexed search snippets
of those same outlets. Directionally reliable; re-verify exact numbers against primary reports
before treating them as hard targets. Each panel ends with STRONG CLAIMS / WEAK SPOTS sections —
read the weak spots before acting on that panel's numbers.
